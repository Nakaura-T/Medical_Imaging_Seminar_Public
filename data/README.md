# データ

このフォルダの中身はGitで管理しません（この `README.md` を除く）。各回のノートブックが、必要なデータをここにダウンロードします。

## 講座で使うデータ（候補）

| データ | 画像 | 使う回 | 入手方法 | 利用条件 |
|---|---|---|---|---|
| scikit-image付属のファントム画像 | 数値ファントム | 1-1 | `scikit-image` に付属 | — |
| pydicom付属のサンプル | CT、MRI（DICOM） | 1-2、2-1、2-2 | `pydicom` に付属 | 要確認 |
| 3次元のCTシリーズ（TCIAの公開データなど） | CT（DICOMシリーズ） | 2-2、3-1、4-1、4-2 | 教員が配布 | 要確認 |
| 複数のシリーズが混ざったフォルダ | CT（DICOM） | 4-1、4-2 | 教員が上のデータから作成 | 上のデータに従う |
| MedMNIST（BreastMNIST） | 乳腺超音波（良性・悪性） | 3-2、3-3、5-1、5-2 | `medmnist` パッケージ | 要確認 |
| MedSegBench（CovidQUExMSBench） | 胸部X線・肺野マスク | 6-1、6-2 | `medsegbench` パッケージ | CC BY-NC-SA 4.0 |
| MedSegBench（BusiMSBench） | 乳腺超音波・腫瘤マスク | 6-2の発展課題 | `medsegbench` パッケージ | CC BY-NC 4.0 |

## 実データの取り扱い

講座では上の公開データだけを使います。
自分や家族の画像など、手元にあるDICOMファイルにも患者情報が含まれます。GitHubやAIサービスには置かないでください。
