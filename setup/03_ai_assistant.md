# AIの使い方とルール

範囲1〜4ではVS CodeのGitHub Copilotを、範囲5〜6ではGoogle Colabに組み込まれたGeminiを使います。

## 1. Copilotの3つの使い方

| 使い方 | 開き方 | 向いている場面 |
|---|---|---|
| セルの中で頼む | セルを選んで `Ctrl+I` | 1つのセルを書く・直す。差分を見てから採用して実行する |
| 解説役に聞く | チャット欄で `tutor` エージェントを選ぶ | コードやエラーの意味を聞く。ファイルは書き換えない |
| Agentに任せる | チャット欄で `Agent` を選ぶ | 複数のセルにまたがる作業 |

範囲1〜2は「セルの中で頼む」と「解説役に聞く」を中心に使い、範囲3からは `Agent` も使ってかまいません。

## 2. 頼む前にコミットする

AIに頼む前に、その時点の状態をコミットします。コミットは自分のパソコンの中に記録を残す操作で、GitHubには送られません。

1. 左端のソース管理（`Ctrl+Shift+G`）を開く
2. メッセージ欄に「AIに頼む前」などと書く
3. 「コミット」を押す

AIに頼んだ後は、ソース管理の画面で変更されたファイルを開き、何が変わったかを確かめます。不要な変更は、ファイルの右にある「変更を破棄」で元に戻せます。

## 3. 頼み方

何のデータに対して、何をして、結果をどう表示してほしいかを書きます。

- 伝わりにくい頼み方：「CT画像を処理して」
- 伝わりやすい頼み方：「変数 `ds` に読み込んだCT画像をCT値に変換し、ウィンドウレベル40、ウィンドウ幅400で表示して」

エラーが出たときは、エラーメッセージをそのまま貼り付けて「このエラーの原因と直し方を教えて」と頼みます。

## 4. AIの答えを確かめる

コードがエラーなく動いても、結果が正しいとは限りません。各回のノートブックにあるチェックリストで確かめます。どの回でも、次の点は確認します。

- 画素値や数値の範囲が想定どおりか
- 画像の枚数、データの件数が想定どおりか
- 画像の向き（上下・左右）が正しいか

## 5. AIに入力してはいけない情報

- 患者の氏名、ID、生年月日などの個人情報、および実際の患者の画像（自分や家族の画像も含む）
- パスワードやアクセスキー
- 利用条件を確認していないデータ

講座で使うデータの患者情報は、評価用に作られた架空のものです。それでも、ヘッダの患者情報をAIに貼り付けて処理させることは、練習の段階から避けてください。

## 6. 課題でのAIの使い方

各回の振り返りに、使ったプロンプトと、AIの答えのうち直した点・採用しなかった点を書きます。AIを使ったこと自体は減点しません。AIの答えを確かめずに使った結果の誤りは、自分の誤りとして扱います。

## 7. Colab（範囲5〜6）でGeminiを使う

範囲5〜6はGPUを使うため、Google Colabで実行します。ColabではCopilotは使えないので、Colabに組み込まれたGeminiに頼みます。

1. ノートブック冒頭の「Open in Colab」ボタンから開く
2. 「ランタイム」→「ランタイムのタイプを変更」でGPUを選ぶ
3. Geminiが変更・追加したセルは、実行する前にコードを読み、何を変えたかを確かめる
4. 作業が終わったら「ファイル」→「ドライブにコピーを保存」で、自分のGoogleドライブに保存する

振り返りの書き方と、5の「入力してはいけない情報」は、Copilotと同じです。

## 8. opencodeを使う場合（任意）

Copilot以外のAIを使いたい人は、VS Codeのターミナルでopencodeを使えます。

- 公式はWindowsではWSLを推奨しています。WSLを使わずに入れる場合は `npm install -g opencode-ai`（Node.jsが必要）などを使います。
- このリポジトリの `AGENTS.md`、`opencode.json`、`.opencode/agents/tutor.md` が読み込まれます。
- 無料モデルの多くは期間限定で、入力がモデルの改善に使われるものもあります。5のルールは同じく守ってください。
