# GitHubアカウントの作成と学生特典の申請

第1回（9/28）の授業中に行います。GitHubの画面の表記は、変わることがあります。

## 1. 用意するもの

- 大学のメールアドレス
- 学生証（申請の途中で、写真の提出を求められることがあります）
- スマートフォン（2段階認証に使います）

## 2. アカウントを作る

1. https://github.com/signup を開く
2. メールアドレス、パスワード、ユーザー名を入力する
3. 登録したメールアドレスに届いた確認コードを入力する

### ユーザー名の決め方

ユーザー名は公開されます。授業の後も、研究や就職活動で使い続けられる名前にしてください。

### 2段階認証を設定する

1. 右上のアイコンから「Settings」を開く
2. 「Password and authentication」を開き、2段階認証（Two-factor authentication）を有効にする
3. スマートフォンの認証アプリ（Microsoft Authenticator、Google Authenticator など）で、表示されたQRコードを読み取る
4. 表示されたリカバリーコードを保存する（スマートフォンをなくしたときに使います）

## 3. 大学のメールアドレスを登録する

1. 「Settings」の「Emails」を開く
2. 大学のメールアドレスを追加する
3. 大学のメールアドレスに届いたメールのリンクを開き、確認を済ませる

## 4. GitHub Educationを申請する

1. https://education.github.com/ を開き、学生向けの特典の申請に進む
2. 在籍している学校として大学名を選び、大学のメールアドレスを選ぶ
3. 求められたら、学生証の写真を提出する
4. 申請を送信する

承認されるまで、数日かかることがあります。承認されると、登録したメールアドレスに通知が届きます。

## 5. 承認されるまでの間

承認前でも、無料版のCopilot（Copilot Free。月あたりの利用回数に上限あり）で授業を進められます。承認されると、学生向けのCopilotが無料で使えるようになります。

VS Codeで承認後もCopilotの利用回数の上限が変わらない場合は、VS Codeの左下のアカウントのアイコンから、いったんサインアウトしてサインインし直します。

## 6. うまくいかないとき

### 申請が却下された

却下の理由がメールまたは申請の画面に表示されます。多いのは、提出した写真で在籍が確認できない場合です。学生証の氏名・大学名・有効期限が読み取れるように撮り直し、再申請します。

### 大学のメールアドレスに確認メールが届かない

迷惑メールのフォルダを確認し、登録したアドレスの綴りに誤りがないか確かめます。それでも届かない場合は、教員に相談してください。
