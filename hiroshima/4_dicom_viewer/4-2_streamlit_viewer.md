## 0. 準備

4-1のノートブックで、基本課題1〜3（`scan_folder`、`load_volume`、`show_slice`）が終わっていることを確かめます。終わっていない場合は、先に4-1に戻ります。

## 1. 解説

### 1-1. Streamlitとは

Streamlitは、Pythonのコードだけで、ブラウザに表示されるアプリを作れるライブラリです。

```python
import streamlit as st

st.title("DICOM Viewer")
index = st.slider("スライス", 0, 151, 76)  # スライダーを表示し、選ばれた値を受け取る
st.write("選んだスライス:", index)
```

`st.slider` はスライダーを画面に表示し、利用者が選んだ値を返します。ほかにも、文字を入力する `st.text_input`、一覧から選ぶ `st.selectbox`、画像を表示する `st.image` などがあります。

### 1-2. ノートブックとアプリの違い

ノートブックでは、セルを上から1回ずつ実行します。Streamlitのアプリは、利用者がスライダーを動かすたびに、**ファイルの先頭から最後までを実行し直します**。

そのため、スライダーを動かすたびに152枚のDICOMを読み込み直すと、表示がとても遅くなります。読み込みの関数に `@st.cache_data` を付けると、同じ引数で呼ばれたときは前回の結果を使い回すので、読み込みは最初の1回だけで済みます。

```python
@st.cache_data
def cached_scan(folder):
    return scan_folder(folder)
```

### 1-3. 関数をファイルにまとめる理由

ノートブックで作った関数は、そのノートブックの中でしか使えません。関数を `dicom_io.py` のようなPythonのファイルにまとめると、アプリからは `from dicom_io import scan_folder` のように読み込んで使えます。

ファイルに分けておくと、読み込みの処理（`dicom_io.py`）と画面の処理（`viewer_app.py`）を別々に直せます。ノートブックで関数を確かめてからアプリに組み込めるので、どこで誤りが起きたのかも探しやすくなります。

## 2. 動かしてみる

ひな形の [viewer_app.py](viewer_app.py) を起動します。VS Codeのターミナルで、リポジトリのフォルダにいることを確かめてから、次を実行します。

```powershell
uv run streamlit run units/4_dicom_viewer/viewer_app.py
```

ブラウザにアプリが表示されます。表示されない場合は、ターミナルに表示された `http://localhost:8501` をブラウザで開きます。

`viewer_app.py` を編集して保存すると、ブラウザの右上に「Rerun」が表示されます。押すと、変更が反映されます。止めるときは、ターミナルで `Ctrl+C` を押します。

## 3. AIに頼んでみる

頼む前に、ソース管理（`Ctrl+Shift+G`）でここまでの状態をコミットします。1つの課題が終わるごとにアプリを起動して動作を確かめ、コミットしてから次の課題に進みます。

アプリがエラーで止まったときは、ブラウザに表示されたエラーメッセージをコピーして、解説役に原因を聞きます。発展課題は、基本課題を終えた人が取り組みます。

### 基本課題1：4-1の関数をファイルにまとめる

4-1で作った関数（`scan_folder`、`load_volume`、`apply_window`）を、`units/4_dicom_viewer/dicom_io.py` にまとめるよう頼みます。`viewer_app.py` から `from dicom_io import scan_folder, load_volume, apply_window` で読み込めることを確かめます。

### 基本課題2：シリーズを読み込んで1枚表示する

入力されたフォルダを `scan_folder` で調べ、最初のシリーズを `load_volume` で読み込み、真ん中のスライスを軟部組織のウィンドウで表示するよう頼みます。1-2のとおり、読み込みには `@st.cache_data` を付けてもらいます。

### 基本課題3：スライダーでスライスを送る

スライダーでスライスの番号を選んで表示できるようにします。今表示しているのが何枚目か（例：「76 / 152」）も表示してもらいます。

### 基本課題4：ウィンドウ幅・レベルを調整する

ウィンドウ幅とウィンドウレベルをスライダーで調整でき、軟部組織・肺野・骨の設定をボタンで選べるようにします。

### 基本課題5：シリーズを選べるようにする

フォルダ内のシリーズを、Modality、SeriesDescription、枚数を並べた一覧から選べるようにします。1枚だけのシリーズ（X線写真）ではスライダーを出さない、表示できないシリーズではエラーのメッセージを出して止まらない、という動きにしてもらいます。

### 発展課題1：ヘッダ情報を表示する

Modality、スライス厚、画素間隔などを画面の横に表示します。患者情報のタグは表示しません。

### 発展課題2：冠状断と矢状断を表示する

4-1の発展課題の処理を使い、断面の向きを切り替えられるようにします。

## 4. AIの答えを確かめる

確認できた項目は `[ ]` を `[x]` に書き換えます。

- [ ] 同じスライス・同じウィンドウの設定で、3D Slicerと見え方が一致した
- [ ] スライダーを最初と最後まで動かしても、エラーにならない
- [ ] スライダーを動かしたとき、読み込み直しで長く待たされない（`@st.cache_data` が効いている）
- [ ] 複数のシリーズが混ざったフォルダで、選んだシリーズの画像だけが表示される
- [ ] `readme.txt` が混ざったフォルダでも、アプリが止まらない
- [ ] 患者情報を画面に表示していない
